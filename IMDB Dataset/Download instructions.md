## ✦ Get the data

The IMDb movie-review dataset is hosted on Kaggle. Download the original CSV archive and extract it before running the notebook.

<div align="center">

### <a href="https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews">⬇️ DOWNLOAD IMDb 50K ON KAGGLE</a>

| Detail | Value |
|:--|:--|

| File | `IMDB Dataset.csv` |
| Columns | `review`, `sentiment` |

## 🚀 Setup in 4 steps

1. Open the [Kaggle dataset page](https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews).
2. Sign in and click **Download**.
3. Extract the ZIP archive and locate `IMDB Dataset.csv`.
4. Place the CSV in the project folder expected by the notebook, then run the notebook.

<details>
<summary>📂 Expected project location</summary>

```text
sarcasm-lens/
├── README.md
├── IMDB_Sentiment_Analysis.ipynb
├── IMDB Dataset.csv
└── own_dataset.xlsx
```

</details>

## ⚡ Quick file check

Your CSV should contain these two columns:

```text
review | sentiment
```

Example labels:

- `positive`
- `negative`

> **Heads-up:** Keep the filename exactly `IMDB Dataset.csv` if your notebook refers to that exact name. If you save it elsewhere, update the dataset path in the notebook.
